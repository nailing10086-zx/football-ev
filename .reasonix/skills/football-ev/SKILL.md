# 足球彩票期望值分析（升级版）

## 触发条件
用户提供竞彩足球赔率截图、比赛ID，或直接给出赔率数据，要求分析最优投注方案。

## 输入
- 积分预算（总投入）
- 每注固定金额（默认 2 分/注）
- 赔率数据：图片截图 / 比赛ID（从 titan007.com 获取） / 文字列出 / 比赛描述
- 分析约束：是否每场必须覆盖、可选过关方式等

---

## 工作流概览

```
输入 → 数据采集 → 数据整理 → 基本面分析 → 概率计算 → 模型预测 → EV计算 → 组合优化 → 输出来
                                                      ↓
                                              赛后复盘（可选）
```

---

## 数据采集

### 方式 A：用户提供赔率截图
使用 `mcp__luma-mcp__image_understand` 识别：
- 每场比赛的对阵双方、联赛、编号、比赛时间
- 每个盘口的「胜/平/负」赔率及让球值 [0]/[+N]/[-N]
- 赔率旁的涨跌箭头（红↑/绿↓）作为走势参考信号

### 方式 B：用户提供比赛ID
从 `https://zq.titan007.com/analysis/{match_id}cn.htm` 使用 `mcp__firecrawl-mcp__firecrawl_scrape` 自动采集：

**数据点：**
- **欧赔（胜平负）**：多机构初盘/即时赔率
- **亚盘（让球盘）**：多机构初盘（"早"）和即时盘（"即"）的盘口和水位
- **大小球盘**：多机构初盘和即时的大小球盘口
- **基本面**：近6场战绩、盘路走势、大球率、赢盘率
- **净胜球分布**：净胜2球+/净胜1球/平局/净输1球/净输2球+
- **历史交锋**：往绩记录
- **阵容信息**：近10场阵容、伤停情况
- **进球时间分布**、**半全场统计**、**相同盘路历史**

使用 `web_fetch` 或 `mcp__firecrawl-mcp__firecrawl_search` 补充球队联赛排名、赛季总战绩等。

### 方式 C：用户文字列出赔率
直接整理成结构化表格。

### 方式 D：用户提供比赛描述
如 "2026.7.27 挪超 奥勒松vs维京" → 搜索确认后使用方式B。

## 数据整理

将所有数据分类为：

1. **基本面**：近期战绩（W/D/L）、进球/失球、主客场差异、联赛排名、积分差距
2. **盘口数据**：欧赔、亚盘、大小球的初盘和即时盘
3. **净胜球分布**：各队本赛季净胜2+/1/0/-1/-2+的场次比例——**评估让球盘概率的关键**
4. **历史交锋**：往绩交战记录
5. **阵容/伤停**：关键球员缺阵影响评估

---

## 基本面分析

### 盘口合理性判断
- 对比两队排名、身价、近期状态，判断盘口设置是否合理
- 盘口偏深（高开）还是偏浅（低开）

### 盘口走势分析
- 比较初盘（"早"）和即时盘（"即"）的变化方向：
  - **升盘**：盘口门槛提高（如半球→半一），通常意味该方受追捧
  - **降盘**：盘口门槛降低（如半一→半球），可能意味该方不被看好
  - **水位调整**：盘口不变但赔率变化
- 判断变化背后的真实意图（真实看好 vs 诱导）

### 欧亚转换
- 检查欧赔转换后的理论亚盘 vs 实际亚盘是否一致
- 识别异常差距（可能为诱盘信号）

## 概率计算

### 隐含概率（从赔率反推）

```
返奖率 = 1 / (1/胜赔 + 1/平赔 + 1/负赔)
某选项隐含概率 = 返奖率 / 该选项赔率
```

### 亚盘概率
```
P(上盘) = 返奖率 / (1 + 上盘水位)
P(下盘) = 返奖率 / (1 + 下盘水位)
```

### 大小球概率
```
P(大球) = 返奖率 / (1 + 大球水位)
P(小球) = 返奖率 / (1 + 小球水位)
```

### 真实概率评估

综合以下维度调整隐含概率：

| 维度 | 权重 | 说明 |
|------|------|------|
| 赔率隐含概率 | 0.35 | 市场定价核心 |
| 基本面分析 | 0.20 | 近况、主客场、往绩 |
| 球队数据分析 | 0.20 | 排名、进失球差 |
| 阵容/伤停 | 0.15 | 关键球员缺阵影响 |
| 战意评估 | 0.10 | 保级/争冠/德比等因素 |

⚠️ **让球盘概率的关键**：评估 [-1]胜 时，必须基于该队本赛季 **净胜2球+的场次比例**。赔率1.32的[0]胜可能合理，但同场的[-1]胜赔率2.20可能被低估或高估，取决于净胜球分布。

## 模型预测

### 亚盘逻辑回归模型
**输入特征**：赔率隐含概率(0.35) + 基本面(0.20) + 球队实力(0.20) + 阵容衰减(0.15) + 战意(0.10)
**输出**：上盘赢盘概率

### 大小球逻辑回归模型
**输入特征**：赔率隐含概率(0.15) + 半场进球模式(0.08) + 角球(0.08) + 联赛因子(0.10) + 净胜球分布(0.10) + 防守伤病系数(0.15) + 环境因素(0.10) + 基本面(0.10) + 往绩(0.05) + xG估算(0.07)

**防守伤病规则**：
- 门将缺阵：向大球方向 +0.75~1 球调整
- 中卫缺阵：向大球方向 +0.5 球调整
- 后腰缺阵：向大球方向 +0.25 球调整
- 叠加有效：多个位置缺阵 → 调整值累加

## 期望值（EV）计算

**单注EV（净利）**：
```
EV = 真实概率 × (赔率 × 每注金额) - 每注金额
期望倍率 = 真实概率 × 赔率
```

- 期望倍率 > 1 → 正期望（+EV）
- 期望倍率 ≤ 1 → 负期望（-EV）

**串关EV**：
```
串关期望倍率 = 各选项期望倍率相乘
串关EV = 串关期望倍率 × 每注金额 - 每注金额
```

> 串关中加入期望倍率 ≤ 1 的选项，会拉低整体期望倍率。
> 因此串关EV ≤ 其中最优单关的EV。

---

## 组合优化

### 场景 A：不强制每场覆盖
1. 找出所有期望倍率 > 1 的选项
2. 按 EV 从高到低排序
3. 全部押到 EV 最高的选项上
4. 如果只有单一正EV选项 → 全押该选项的单关

### 场景 B：每场必须覆盖
1. 找出每场 EV 最高的选项
2. 正EV的作为主力单关重复押
3. 负EV的用最低成本串关兜底（用正EV选项串负EV选项）
4. 对比纯单关覆盖 vs 含串关覆盖的总EV

### 场景 C：允许任意串关
- 同场比赛的两个选项不能串（互斥）
- 串关名称：X串Y = 选X个选项，每Y个组合成一注
- 所有串关组合的期望倍率 = 各选项期望倍率相乘
- 因所有负EV选项期望倍率 ≤ 1，任何包含负EV选项的串关EV ≤ 最优单关EV
- 所以：全部押最优单关即可

## 赛后复盘（可选）

用户提供比赛结果后：

1. **数据回溯**：调取赛前所有数据和分析记录
2. **偏差分析**：对比预测 vs 实际

| 组件 | 预测 | 实际 | 偏差 |
|------|------|------|------|
| 赛果 | 胜/平/负 | 胜/平/负 | 对/错 |
| 让球盘结果 | 赢/输 | 赢/输 | 对/错 |
| 大小球结果 | 大/小 | 大/小 | 对/错 |

3. **根因分析**：赔率判断错？基本面误判？突发因素？
4. **权重优化**：根据偏差调整评估权重
5. **准确率追踪**：

```
总分析场次: N
让球盘准确率: X/N (XX%)
大小球准确率: X/N (XX%)
```

## 输出格式

### 简洁模式
- 各选项 EV 排名
- 最优买法（赔率、投入）
- 期望回报
- 中奖概率

### 完整模式（默认）
- 每场比赛数据分析摘要
- 所有盘口选项的概率与EV表
- 最优投注方案（含串关覆盖）
- 中奖场景分解（概率 + 回报）
- 期望总积分
- 关键假设提醒（真实概率与市场隐含概率的偏差风险）

---

## 风险提示
- 所有EV计算基于评估概率，不是已知事实
- 正EV方案的风险阈值：真实概率 < 赔率的倒数（1/赔率）则方案从正期望变负期望
- 建议理性投注，量力而行
