# 足球彩票期望值分析（升级版）

## 触发条件
用户提供竞彩足球赔率截图、比赛ID，或直接给出赔率数据，要求分析最优投注方案。

## 输入
- 积分预算（总投入）
- 每注固定金额（默认 2 分/注）
- 赔率数据：图片截图 / 比赛ID（从 titan007.com 获取） / 文字列出 / 比赛描述
- 分析约束：是否每场必须覆盖、可选过关方式等

---

## 工作流概览

```
输入 → 数据采集 → 数据整理 → 基本面分析 → 概率计算 → 模型预测 → EV计算 → 组合优化 → 输出来
                                                      ↓
                                              赛后复盘（可选）
```

## 数据整理

将所有数据分类为：

1. **基本面**：近期战绩（W/D/L）、进球/失球、主客场差异、联赛排名、积分差距
2. **盘口数据**：欧赔、亚盘、大小球的初盘和即时盘
3. **净胜球分布**：各队本赛季净胜2+/1/0/-1/-2+的场次比例——**评估让球盘概率的关键**
4. **历史交锋**：往绩交战记录
5. **阵容/伤停**：关键球员缺阵影响评估

## 基本面分析

### 盘口合理性判断
- 对比两队排名、身价、近期状态，判断盘口设置是否合理
- 盘口偏深（高开）还是偏浅（低开）

### 盘口走势分析
- 比较初盘（"早"）和即时盘（"即"）的变化方向：
  - **升盘**：盘口门槛提高（如半球→半一），通常意味该方受追捧
  - **降盘**：盘口门槛降低（如半一→半球），可能意味该方不被看好
  - **水位调整**：盘口不变但赔率变化
- 判断变化背后的真实意图（真实看好 vs 诱导）

### 欧亚转换
- 检查欧赔转换后的理论亚盘 vs 实际亚盘是否一致
- 识别异常差距（可能为诱盘信号）

## 概率计算

### 隐含概率（从赔率反推）

```
返奖率 = 1 / (1/胜赔 + 1/平赔 + 1/负赔)
某选项隐含概率 = 返奖率 / 该选项赔率
```

### 亚盘概率
```
P(上盘) = 返奖率 / (1 + 上盘水位)
P(下盘) = 返奖率 / (1 + 下盘水位)
```

### 大小球概率
```
P(大球) = 返奖率 / (1 + 大球水位)
P(小球) = 返奖率 / (1 + 小球水位)
```

### 真实概率评估

综合以下维度调整隐含概率：

| 维度 | 权重 | 说明 |
|------|------|------|
| 赔率隐含概率 | 0.35 | 市场定价核心 |
| 基本面分析 | 0.20 | 近况、主客场、往绩 |
| 球队数据分析 | 0.20 | 排名、进失球差 |
| 阵容/伤停 | 0.15 | 关键球员缺阵影响 |
| 战意评估 | 0.10 | 保级/争冠/德比等因素 |

⚠️ **让球盘概率的关键**：评估 [-1]胜 时，必须基于该队本赛季 **净胜2球+的场次比例**。赔率1.32的[0]胜可能合理，但同场的[-1]胜赔率2.20可能被低估或高估，取决于净胜球分布。

## 模型预测

### 亚盘逻辑回归模型
**输入特征**：赔率隐含概率(0.35) + 基本面(0.20) + 球队实力(0.20) + 阵容衰减(0.15) + 战意(0.10)
**输出**：上盘赢盘概率

### 大小球逻辑回归模型
**输入特征**：赔率隐含概率(0.15) + 半场进球模式(0.08) + 角球(0.08) + 联赛因子(0.10) + 净胜球分布(0.10) + 防守伤病系数(0.15) + 环境因素(0.10) + 基本面(0.10) + 往绩(0.05) + xG估算(0.07)

**防守伤病规则**：
- 门将缺阵：向大球方向 +0.75~1 球调整
- 中卫缺阵：向大球方向 +0.5 球调整
- 后腰缺阵：向大球方向 +0.25 球调整
- 叠加有效：多个位置缺阵 → 调整值累加

## 期望值（EV）计算

**单注EV（净利）**：
```
EV = 真实概率 × (赔率 × 每注金额) - 每注金额
期望倍率 = 真实概率 × 赔率
```

- 期望倍率 > 1 → 正期望（+EV）
- 期望倍率 ≤ 1 → 负期望（-EV）

**串关EV**：
```
串关期望倍率 = 各选项期望倍率相乘
串关EV = 串关期望倍率 × 每注金额 - 每注金额
```

> 串关中加入期望倍率 ≤ 1 的选项，会拉低整体期望倍率。
> 因此串关EV ≤ 其中最优单关的EV。

---

## 组合优化

### 场景 A：不强制每场覆盖
1. 找出所有期望倍率 > 1 的选项
2. 按 EV 从高到低排序
3. 全部押到 EV 最高的选项上
4. 如果只有单一正EV选项 → 全押该选项的单关

### 场景 B：每场必须覆盖
1. 找出每场 EV 最高的选项
2. 正EV的作为主力单关重复押
3. 负EV的用最低成本串关兜底（用正EV选项串负EV选项）
4. 对比纯单关覆盖 vs 含串关覆盖的总EV

### 场景 C：允许任意串关
- 同场比赛的两个选项不能串（互斥）
- 串关名称：X串Y = 选X个选项，每Y个组合成一注
- 所有串关组合的期望倍率 = 各选项期望倍率相乘
- 因所有负EV选项期望倍率 ≤ 1，任何包含负EV选项的串关EV ≤ 最优单关EV
- 所以：全部押最优单关即可

## 实战教训（从实际分析中积累）

### 概率评估原则
1. **保守优先**：宁可低估正EV，不要高估。第一次算太松（场场正EV），第二次算太紧（全打成负），都不对。每场的概率评估必须有具体数据支撑。
2. **数据不足时承认**：如波兹南VS奥胡斯（欧冠），对两队实力无可靠数据时不能硬给概率。数据不完整的比赛宁可跳过。
3. **对手实力不可忽视**：阿拉木图主场虽强，但奥莫尼亚身价更高(0.15>0.126亿)、首回合1-0胜，阿拉木图翻盘概率不是52%而是~48%。
4. **净胜球分布是让球盘关键**：评估[-1]胜时必须有该队净胜2+的场次比例数据，不能靠猜测。如弗拉门戈主场87.5%的赢球净胜2+可以支撑60%的评估，但客场没有数据就不能硬给。
5. **保级队vs争冠队**：联赛排名差确定性强（如第1打第13），但排名接近（第4vs第6只差2分）时不能高估。

### 过关方式选择
1. **所有负EV选项期望倍率 ≤ 1**，任何包含负EV选项的串关都会拉低整体EV。
2. **M串N（过M关）**：当6个选项全正EV时，过4关回报率最高，4关+6关综合最优。
3. **单关是底线**：如果找不到可靠的正EV，就只打单关或干脆不投。

### 期望计算验证
1. 中6场奖金 = 4串1全中(15注求和) + 6串1(1注)。之前把6串1的367倍错算成总奖金（少加了4串1部分又多乘了），实际约2411分不是8166分。
2. 所有计算结果必须交叉验证，大数字特别容易出错。
3. **必须穷举计算**：手算容易漏组合，用脚本枚举所有场次子集×过关方式，输出中奖率/回本率/期望净利/资金效率，禁止凭感觉给结论。

## 学术建模方法（吸收自概率学论文讨论）

### 去水处理（庄家抽水还原）
```
Q = 1/赔率（庄家隐含概率）
总边际 = ΣQ（胜平负，通常 1.05~1.10）
P_bookie = Q / 总边际（去水后的庄家真实估计）
```
**下注决策条件：P_real > P_bookie 才下注（正EV）。**

### 双模系统（关键！按用户类型选模型）
| 用户类型 | 模型 | 核心 |
|---------|------|------|
| 高频玩家（每天>10注） | 分数凯利（1/4~1/2） | f* = (bp-q)/b，追求长期增长 |
| **低频玩家（每周<3注，爱串关）** | **期望阈值+方差覆盖** | **不算仓位%，算盈亏平衡概率** |

**低频用户不要用凯利**——凯利假设大数定律（重复很多次），而低频用户只买一两注，方差主宰结果。低频用户的最优是"容错串关（M选N）+ 期望阈值"。

### 容错串关（M选N）建模
本质是**购买覆盖区间**，不是单纯下注。核心目标不是最大化"全中概率"，而是**最大化"命中N场时保本/盈利的概率"**。

```
E(R) = [P(中4场)×中4奖金 + P(中5场)×中5奖金 + P(中6场)×中6奖金] / 总投入
决策阈值：E(R) > 0.85 才建议购买，否则显示"不建议购买"
```

### 赔率梯队原则（反直觉！）
6场不能全选低赔稳胆（1.05×6≈1.34，扣水后不赚钱）。必须混搭：
```
3场准稳胆(1.3~1.5) + 2场均势盘(1.8~2.2) + 1场冷门(3.0+)
```
这样错1~2场时返还依然覆盖投入。**目标不是全中，是"中N场保本"概率最高。**

### 加权注码法
15注不平均分配。包含高赔冷门的组合给更高权重，全稳胆组合给最低权重。
效果：冷门打出时中4场奖金是平均注码的2~3倍；冷门没中，稳胆全中也能保本。

### 风险厌恶效用模型（论文深度）
```
Max U = E(V) - λ/2 × Var(V)    （λ = 风险厌恶系数）
```
λ高（厌恶风险）时，低赔率无肉场次直接输出"投注金额=0"。

### 容错串关期望简化公式
```
E = Σ_{i=1}^{C(n,k)} (∏_{j∈组合i} b_j) × (∏_{j∈组合i} p_j)
```
算法任务：在候选比赛中贪婪搜索，找出让 E 最大化、同时"中k场保本概率"最高的组合。

### 核心结论（论文升华）
- 高频→凯利增长；低频→二项式覆盖（容错串关+期望阈值）
- 单次博弈的"最优"= 最大化中奖覆盖概率，而非长期增长率
- 用户感知的"赚得多"来自赔率梯队混搭 + 加权注码，不来自单关低赔率

## 学术建模·最终定稿（Poisson-Log Kelly 串关模型）

> 完整推导见项目根目录《论文-泊松凯利串关模型.md》。以下是可直接套用的核心框架。

### 符号速查
- `p_w/p_d/p_l`：赢全/走水/输全概率（整数盘）
- `b = Odds-1`：净赔率；`R`：总返还倍数（含本金，R<1 即亏损）
- `C`：组合总成本；`f`：总资金投入比例
- **关键区分：`P_pass`（过关概率，走水算过）≠ `P_breakeven`（回本概率，奖金≥C）**

### 完整流程（每轮分析严格按此执行）
1. **概率引擎**：Dixon-Coles 加权泊松，估计每场 `(p_w, p_d, p_l)`；净胜球卷积 P(D=d)=ΣP(X_h=k+d)P(X_a=k)
2. **价值筛选**：去水 `q=(1/Odds)/M`；`EV=p_w·b - p_l > 0` 且 `Odds≥1.3` 才入选
3. **组合构建**：6场4串1（C(6,4)=15注），穷举 3^6=729 种微观结果，算收益分布、P_breakeven、E
4. **组合筛选**：`U = λ·P̃_breakeven + (1-λ)·Ē`（Min-Max 归一化，λ 越大越保守）
5. **仓位优化**：`max E[log(1-f+f·R)]` 求 f*，实际用 1/4 分数凯利
6. **成本衔接**：`f_exec×总资金 < C` 则不买；≥C 买 floor(f_exec×总资金/C) 注

### 三结果凯利（单场整数盘）
```
f* = [p_w·b - p_l] / [b·(p_w + p_l)]     # 走水项求导抵消，不进公式
保守：p_w' = p_w - ασ, p_l' = p_l + ασ   # 概率守恒（败率上调）
```
> ⚠️ 坑：把走水计入胜率会虚高仓位；组合收益是分段非线性，不能当单资产套凯利。

### 容错串关要点
- 目标 = 最大化"中N场保本概率"，不是全中概率
- 赔率梯队：3场稳胆(1.3~1.5) + 2场均势(1.8~2.2) + 1场冷门(3.0+)
- 中4场奖金取决于中哪4场（赔率乘积不同），**必须逐场景穷举**，不能假设"中4场=回本"
- 独立泊松下 6场=729 微观结果；同联赛/德比存在相关性未建模（局限）

### 双模选择
| 场景 | 模型 |
|------|------|
| 高频多注 | 分数凯利（追求长期增长） |
| 低频一两注（现实用户） | 容错串关 + P_breakeven 筛选 + 对数效用定仓 |
